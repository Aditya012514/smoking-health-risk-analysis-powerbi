# 📊 Smoking Health Risk Analysis Dashboard

An interactive **Power BI dashboard** designed to analyze smoking patterns and their relationship with different health conditions.

This is my **first Power BI project**, created as part of my journey into Data Analytics and Business Intelligence. The project focuses on transforming healthcare-related data into meaningful visual insights using Power BI, Power Query, and DAX.

---

## 📌 Project Overview

The **Smoking Health Risk Analysis Dashboard** provides an interactive view of smoking habits, patient demographics, and health-related conditions.

The dashboard allows users to explore the data through interactive organ and condition selections, while dynamically updating key metrics and visuals.

The analysis is based on **500 patient records** containing information related to age, gender, smoking habits, BMI, cholesterol, hypertension, and organ conditions.

## 📈 Dashboard Analysis

### 1. Patient & Health KPIs

The dashboard provides key metrics including:

- Total Patients
- Average Age
- Average BMI
- Average Smoking Years
- Average Daily Cigarette Intake

### 2. Smoking Analysis

The dashboard analyzes:

- Current Smokers
- Former Smokers
- Non-Smokers
- Smoking status by gender
- Smoking duration
- Daily cigarette intake

### 3. Health Risk Analysis

The dashboard explores:

- Cholesterol risk levels
- Hypertension
- Heart condition
- Lung condition
- Kidney condition
- Liver condition
- Overall health condition

### 4. Interactive Organ Analysis

Users can select:

- ❤️ Heart
- 🫁 Lungs
- 🫘 Kidney
- 🧬 Liver
- 🧍 Human Body

The dashboard dynamically updates the selected organ's patient count and visual representation.

Users can also switch between:

- Healthy
- Damaged

to explore the corresponding condition.

---

## 🔄 Interactive Dashboard

The project uses **DAX measures and disconnected selector tables** to create dynamic interactions.

When an organ or condition is selected, the dashboard dynamically updates:

- Selected Organ Patients
- Organ image
- Healthy/Damaged visualization

This makes the dashboard more interactive than a collection of static charts.
